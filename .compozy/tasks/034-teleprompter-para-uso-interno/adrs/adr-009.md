# ADR-009: Build com electron-vite, instaladores com electron-builder publicados pelo GitHub Actions

## Status

Accepted

## Date

2026-11-24

## Context

As preferências da equipe fixam Electron, React e TypeScript (#24), Windows e Mac (#24), instaladores sem assinatura (#24) e distribuição pelas Releases de um repositório público na conta `audiovisualpecege` (#31), com aviso de versão nova e botão que abre o instalador (#24). O instalador do Mac só é gerado num Mac, e esta máquina é Windows.

## Decision

- **Build:** `electron-vite` (Vite para processo principal, preload e telas), com React e TypeScript.
- **Instaladores:** `electron-builder`: NSIS no Windows (x64, atalho no menu Iniciar, ícone próprio, associação `.roteiro`), DMG no Mac para x64 e arm64 (assinatura ad hoc, exigida pelo arm64, sem certificado da Apple).
- **Publicação:** repositório `audiovisualpecege/teleprompter`. Um workflow do GitHub Actions, disparado por tag `v*`, gera os instaladores em `windows-latest` e `macos-latest` e os anexa à Release da tag. O Windows também pode ser gerado localmente.
- **Aviso de versão nova:** ao abrir, o processo principal consulta `https://api.github.com/repos/audiovisualpecege/teleprompter/releases/latest` (sem token, limite de 5 segundos), compara versões semânticas e, se houver mais nova, a tela de controle oferece "Baixar e instalar": o instalador do sistema é baixado para a pasta Downloads e aberto. Sem atualização silenciosa.

## Alternatives Considered

### Alternative 1: Electron Forge

- **Description**: Ferramenta oficial de empacotamento.
- **Pros**: Mantida pela equipe do Electron.
- **Cons**: DMG para duas arquiteturas e associação de arquivo exigem mais configuração; menos material para NSIS.
- **Why rejected**: electron-builder cobre tudo com uma configuração só.

### Alternative 2: Atualização automática (electron-updater)

- **Description**: Baixar e instalar sozinho.
- **Pros**: Menos passos para quem usa.
- **Cons**: Exige assinatura no Mac e contraria a preferência #24 (sem atualização silenciosa).
- **Why rejected**: Preferência da equipe.

## Consequences

### Positive

- Instaladores dos dois sistemas a cada tag, sem precisar de um Mac na equipe técnica.

### Negative

- Windows SmartScreen e Gatekeeper avisam na primeira abertura; o Como usar explica como liberar.

### Risks

- Limite de consultas da API do GitHub sem token (60 por hora por IP). Mitigação: uma consulta por abertura; falha é silenciosa.

## Implementation Notes

- `version` do `package.json` é a fonte única da versão; o Vite a injeta nas telas no build.
- Os modelos de voz são baixados pelo script `scripts/baixar-modelos.mjs` (SHA-256 fixado) antes do empacotamento, no Actions e localmente, e não entram no git.
- Os instaladores gerados são listados em `_instaladores.txt`.
